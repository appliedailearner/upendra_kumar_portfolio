=== Sheet: Agentic AI Arch Mistakes ===
   Mistake #                                Common Architecture Mistake                                                            Why It Happens                                                                               Why It Is Dangerous                                                                      Correct Architecture Pattern                                                                                          What To Say In Interviews
0          1  Using a single LLM agent for complex enterprise workflows  Most demos show one agent answering questions, so teams copy that design  Single agents become unreliable when tasks require planning, validation, and external tool usage   Use multi-agent orchestration with coordinator + worker agents (planner, researcher, validator)     Explain that complex workflows should be decomposed into multiple agents coordinated by an orchestration layer
1          2             Directly connecting LLMs to enterprise systems       Developers expose APIs directly to the LLM through tools or plugins                                             This creates security, auditing, and governance risks          Introduce an API mediation layer using API Management, Functions, and policy enforcement  Explain that enterprise agents should interact with systems through a controlled API layer with auditing and RBAC
2          3           Ignoring enterprise governance and observability                        Many prototypes focus only on model output quality                  Production AI systems require monitoring, identity controls, and cost visibility  Add governance layers: Entra ID, Key Vault, RBAC, telemetry, content safety, and cost monitoring    Explain that enterprise AI platforms must include identity, secrets management, monitoring, and safety controls
