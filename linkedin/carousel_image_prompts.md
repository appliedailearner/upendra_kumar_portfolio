## Usage Instructions

### For ChatGPT (DALL-E):
1. Copy prompt above
2. Paste into ChatGPT
3. Add: "Generate this as a 1080x1080px image"
4. Download the generated image

### For Midjourney:
1. Copy prompt above
2. Add `--ar 1:1 --v 6` at the end
3. Paste in Discord: `/imagine [prompt] --ar 1:1 --v 6`
4. Upscale and download

### For Leonardo.ai:
1. Copy prompt above
2. Select "Graphic Design" preset
3. Set dimensions to 1024x1024
4. Generate and download

### For Adobe Firefly:
1. Copy prompt above
2. Select "Text to Image"
3. Set aspect ratio to 1:1
4. Generate and download

## Pro Tips

1. **Consistency**: Generate all slides in the same session for consistent style
2. **Regenerate**: If a slide doesn't look right, regenerate with slight prompt tweaks
3. **Edit**: Use Canva to add final text overlays for perfect typography
4. **Brand Colors**: Add "Use purple #A855F7 and blue #3B82F6" to prompts for consistency
5. **Test**: View on mobile before posting to ensure readability
